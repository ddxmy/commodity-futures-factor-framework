# Carry因子表现

## 当前结论

**状态：Degrading。** 主力/次主力Carry在2010–2022研究样本中表现强，K从30增加
至120时结果平滑改善，H1、H5和H10方向一致；2023年至今的K120标准报告接近零
收益，RankIC也不再显著。当前不能把早期结果视为已通过近期样本验证。

数据截至 `2026-07-10`。

## 因子定义

Carry使用按成交量排名的A、B合约收盘价：

```text
daily_carry   = -(close_B - close_A) / close_A × 365 / d_AB
main_sub_carry = daily_carry过去K个交易日的完整窗口均值
```

A、B是流动性排名，不保证期限先后；`d_AB`使用带符号的到期日差。默认K为90。
信号在收盘后形成，下一交易日开盘执行。

## 已知异常

`results/carry/carry-20100101-20221231/every_5_trading_days/` 的目录名以
`20221231`结尾，但内部 `run_config.csv` 的结束日期为 `20211231`。登记表以配置文件
为准，暂不把该报告视为完整的2010–2022样本，也不擅自修改原结果目录。

## 风险与下一步

- Carry使用收盘价而不是结算价，结算价版本应作为新口径单独回测。
- 近期结果接近零，需要检查分品种贡献，判断是否由品种扩容或某些板块造成。
- K=120位于现有网格边界，应测试180、252等更长窗口，避免边界最优误判。
- 继续保留Rank作为主口径，不因Z-score偶尔更好而切换主结果。
