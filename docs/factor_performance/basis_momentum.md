# 基差动量因子表现

## 当前结论

**状态：Degrading。** AB、K=252在2010–2022研究样本中表现强，IC、RankIC和
分组单调性均支持有效性；2023年至今仍有正收益，但RankIC、Sharpe和多头端贡献
明显下降。当前证据支持“长期有效、近期衰减”，不支持把早期Sharpe直接外推。

数据截至 `2026-07-10`。

## 因子定义

AB变体使用按成交量排名的A、B合约：

```text
daily_factor_AB = (daily_return_A - daily_return_B) / d_AB × 365
factor_AB       = daily_factor_AB过去K个交易日的完整窗口均值
```

A、B是流动性排名，不保证期限先后；`d_AB`使用带符号的到期日差。当前信号使用
合约收盘价计算的close-to-close对数收益。信号在收盘后形成，下一交易日开盘执行。

## 分组与收益来源

2010–2022的G1至G5平均周收益严格单调，Spearman单调性为1.00。平均每周：

- G1：0.2480%，G5：-0.1475%。
- 做多G1贡献0.1240%，做空G5贡献0.0738%。
- 多空组合平均收益0.1978%。

2023年至今单调性降至0.30，G1平均收益为负，多空收益更多来自做空G5。这是近期
衰减的重要证据，不能只看最终净值仍高于1。

## 风险与下一步

- 2023年至今样本较短，且结束于2026年7月，属于不完整自然年。
- 当前H×K报告只覆盖2010–2022；近期样本尚无同口径H×K矩阵。
- K越长表现越好，需要继续测试252附近的参数邻域，避免只比较到最优边界。
- 当前使用收盘收益构造因子，而不是结算价；公式口径变化必须另建版本。

下一步优先补充2023年至今的K×H矩阵，并比较K=180、252、360附近是否保持平滑。
