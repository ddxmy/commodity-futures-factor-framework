# 运行命令与结果文件示例

本文按“想得到什么结果”列出对应命令、输出目录和主要文件。所有命令都应在项目根目录运行。
结果按因子归档：默认结构为
`results/<factor_name>/<原报告目录>/`。自定义 `--result-dir` 时，该参数仍表示
结果根目录，框架会在其下继续创建因子子目录。

```bash
cd commodity-futures-factor-framework
```

核心行情、交易日历和可交易池覆盖 `20070104—20260710`。对于
`K=90` 的 Carry，首次达到至少10个流动性合格品种的日期为
`20080129`；2010年每日约有17至20个有效品种。因此本文将
`20100101—20221231` 和 `20230101—20260710` 作为主要的前后样本。

## 结果类型速查

| 目标 | 使用入口 | 主要结果 |
|---|---|---|
| 单个 K 的完整因子报告 | `python main.py` | Rank/Z-score 净值、策略指标、IC、RankIC、五组收益和图表 |
| 每 H 个交易日调仓 | `python main.py --rebalance-freq H` | 完整因子报告，调仓序列从样本首个交易日开始 |
| 每周最后交易日调仓 | `python main.py --rebalance-freq W-FRI` | 完整周频报告，周五休市时使用当周最后一个实际交易日 |
| 比较多个 K 和 H | `python -m src.hk_robustness` | K×H 明细、汇总表及三张热力图 |
| 只比较多个 K、固定 H=5 | `python -m src.hk_robustness --h-values 5` | 每个 K 的 H=5 Rank 组合指标和单列热力图 |
| 五因子 Top40 逆波动率策略 | `python -m src.multi_factor_strategy` | 两种仓位方法、五因子及等权组合 NAV、年度指标、IC/RankIC 和期货池审计表 |

选择入口时遵循下面的简单规则：

- 想查看一个参数的完整研究报告，使用 `main.py`。
- 想批量比较多个 K/H，使用 `src.hk_robustness`。
- `main.py` 同时运行 Rank 和 Z-score；H×K 工具只运行 Rank，以减少耗时。

## 五因子 Top40 逆波动率策略

该入口每年1月和7月的首个交易日，使用严格早于筛选日的120个交易日平均成交额选择 Top 40 品种。策略每日调仓，使用20日固定合约收盘收益率波动率，交易合约要求至少剩余45个自然日到期。信号在 T 日收盘后形成，最早于 T+1 日开盘执行。

默认运行 `20200101—20260701`：

```bash
python -m src.multi_factor_strategy \
  --start 20200101 \
  --end 20260701
```

默认不覆盖同路径中的旧结果。确认要重跑同一组参数时，显式加上：

```bash
python -m src.multi_factor_strategy \
  --start 20200101 \
  --end 20260701 \
  --overwrite
```

`--overwrite` 只允许指定的策略结果文件被重写，不会删除结果目录，也不会处理其他未知文件。

默认输出目录：

```text
results/multi_factor_strategy/
  top40_amount120_vol20-20200101-20260701/
    daily/
```

`daily/` 根目录包含：

- `universe_ranking.csv`：每次半年筛选的完整排名、观测数、生效区间和进出状态。
- `universe_members.csv`：每个半年期实际入选的 Top 40 品种。
- `universe_changes.csv`：新进和退出品种的紧凑记录。
- `strategy_metrics.csv`：五个因子及等权组合在两种仓位方法下的全区间指标。
- `factor_ic_summary.csv`、`factor_ic_series.csv`、`factor_ic_annual.csv`：各因子的 IC 和 RankIC。
- 五个因子的两方法 NAV 对比图，以及 `combined_nav_comparison.png`。

两个方法子目录为：

```text
full_pool_invvol/
tail10_invvol/
```

每个子目录都包含 `daily_returns.csv`、`nav.csv`、`daily_diagnostics.csv`、`weights.csv`、`annual_metrics.csv`、`annual_returns.csv` 和 `nav_summary.png`。`tail10_invvol` 使用当日合格期货池前10%做多、后10%做空，数量按向上取整；两种方法均对多空两侧独立归一化为 `+0.5/-0.5`。

## 1. 单个 K 的完整 Carry 报告

### 1.1 日频调仓

以下命令使用 `K=90`，每天形成信号，并在下一交易日开盘执行：

```bash
python main.py \
  --factor carry \
  --factor-param lookback=90 \
  --start 20190101 \
  --end 20260710 \
  --rebalance-freq 1
```

输出目录：

```text
results/carry/carry-20190101-20260710/daily/
```

### 1.2 每5个交易日调仓

这里 `H=5`。调仓信号日从样本第一个交易日开始，之后选择第 `1+5n` 个交易日；它不保证落在周五。

```bash
python main.py \
  --factor carry \
  --factor-param lookback=90 \
  --start 20190101 \
  --end 20260710 \
  --rebalance-freq 5
```

输出目录：

```text
results/carry/carry-20190101-20260710/every_5_trading_days/
```

### 1.3 周频调仓

`W-FRI` 表示每个自然周最后一个实际交易日。正常情况下是周五；周五休市时自动提前，不会跳过整周。

```bash
python main.py \
  --factor carry \
  --factor-param lookback=90 \
  --start 20190101 \
  --end 20260710 \
  --rebalance-freq W-FRI
```

输出目录：

```text
results/carry/carry-20190101-20260710/weekly_last_trading_day/
```

## 2. 分样本运行 H=5

如果目的是比较前后两个时期，推荐使用互不重叠的样本：

- 前段：`20100101—20221231`
- 后段：`20230101—20260710`

### 2.1 用 main.py 跑 K=90 的完整报告

前段：

```bash
python main.py \
  --factor carry \
  --factor-param lookback=90 \
  --start 20100101 \
  --end 20221231 \
  --rebalance-freq 5
```

后段：

```bash
python main.py \
  --factor carry \
  --factor-param lookback=90 \
  --start 20230101 \
  --end 20260710 \
  --rebalance-freq 5
```

输出目录：

```text
results/carry/carry-20100101-20221231/every_5_trading_days/
results/carry/carry-20230101-20260710/every_5_trading_days/
```

这个切分把2022年完整归入前段，并从2023年开始观察近期表现，两个区间没有重叠。

### 2.2 用 main.py 跑全部 K

Carry 的标准输出目录名目前不包含 K。同一日期区间、同一调仓频率连续运行多个 K 会写入同一个目录，后一次会覆盖前一次。因此使用 `main.py` 批量跑 K 时，必须为每个 K 指定独立结果根目录。

前段：

```bash
for K in 30 60 90 120; do
  python main.py \
    --factor carry \
    --factor-param lookback=$K \
    --start 20100101 \
    --end 20221231 \
    --rebalance-freq 5 \
    --result-dir results/carry_main_K$K
done
```

后段：

```bash
for K in 30 60 90 120; do
  python main.py \
    --factor carry \
    --factor-param lookback=$K \
    --start 20230101 \
    --end 20260710 \
    --rebalance-freq 5 \
    --result-dir results/carry_main_K$K
done
```

例如 `K=90` 的结果位于：

```text
results/carry_main_K90/carry/carry-20100101-20221231/every_5_trading_days/
results/carry_main_K90/carry/carry-20230101-20260710/every_5_trading_days/
```

每个 K 都会得到完整的 Rank/Z-score、IC/RankIC 和分组报告。

## 3. 固定 H=5，批量比较全部 K

如果只需要比较 `K=[30,60,90,120]`，不需要每个 K 的完整净值和五组图，使用 H×K 工具更方便。

前段：

```bash
python -m src.hk_robustness \
  --factor carry \
  --start 20100101 \
  --end 20221231 \
  --k-values 30 60 90 120 \
  --h-values 5
```

后段：

```bash
python -m src.hk_robustness \
  --factor carry \
  --start 20230101 \
  --end 20260710 \
  --k-values 30 60 90 120 \
  --h-values 5
```

输出目录：

```text
results/carry/carry-robustness-20100101-20221231-K30_60_90_120-H5/
results/carry/carry-robustness-20230101-20260710-K30_60_90_120-H5/
```

每个目录包含：

```text
robustness_details.csv
robustness_summary.csv
net_sharpe_heatmap.png
rank_ic_heatmap.png
annual_return_heatmap.png
```

注意：H×K 目录名会包含完整 K/H 网格，因此相同日期下的不同网格可以共存。如果需要重跑完全相同的因子、日期和网格，请指定新的结果根目录：

```bash
python -m src.hk_robustness \
  --factor carry \
  --start 20230101 \
  --end 20260710 \
  --k-values 30 60 90 120 \
  --h-values 5 \
  --result-dir results/robustness_rerun_01
```

此时输出到：

```text
results/robustness_rerun_01/carry/carry-robustness-20230101-20260710-K30_60_90_120-H5/
```

## 4. 完整 H×K 热力图

下面的轻量网格使用四个回看窗口和三个持仓周期，共运行12组 Rank 组合：

```bash
python -m src.hk_robustness \
  --factor carry \
  --start 20220101 \
  --end 20251231 \
  --k-values 30 60 90 120 \
  --h-values 1 5 10
```

输出目录：

```text
results/carry/carry-robustness-20220101-20251231-K30_60_90_120-H1_5_10/
```

热力图中：

- 纵轴是回看窗口 K。
- 横轴是持仓/调仓周期 H。
- `net_sharpe_heatmap.png` 展示费后 Sharpe。
- `rank_ic_heatmap.png` 展示 RankIC 均值。
- `annual_return_heatmap.png` 展示费后年化收益。

整数 H 均以样本首个交易日为调仓序列锚点。`H=5` 与 `W-FRI` 不是同一调仓序列；若要使用行业常见的周末信号，应单独通过 `main.py --rebalance-freq W-FRI` 运行。

## 5. 标准报告文件说明

`main.py` 的每个标准报告目录包含以下文件：

| 文件 | 内容 | 常见用途 |
|---|---|---|
| `run_config.csv` | 因子参数、日期、成本、调仓频率等 | 确认研究口径，复现结果 |
| `strategy_metrics.csv` | Rank 和 Z-score 的收益、波动、Sharpe、回撤、换手与成本 | 比较策略总体表现 |
| `strategy_nav.csv` | 两种组合的逐日净值 | 二次作图和时期分析 |
| `strategy_nav.png` | Rank/Z-score 净值图 | 快速查看策略走势 |
| `ic_summary.csv` | IC、RankIC 均值、ICIR、t检验和Newey-West检验 | 判断因子预测能力和显著性 |
| `ic_series.csv` | 每个信号日的 IC、RankIC 和有效商品数 | 检查稳定性、滚动表现和异常日期 |
| `ic_rankic_rolling20.png` | IC/RankIC 及20期滚动均值 | 查看预测能力是否随时间衰减 |
| `group_returns.csv` | G1至G5及多空组合的单期收益 | 检查单调性和多空收益来源 |
| `group_nav.csv` | G1至G5及多空组合的累计净值 | 二次分析分组表现 |
| `five_group_nav.png` | 五组累计净值图 | 直观看因子排序是否单调 |

ICIR 的年化口径会随调仓频率变化：

- 日频：乘以 `sqrt(252)`。
- 整数 H：乘以 `sqrt(252/H)`。
- 周频：乘以 `sqrt(52)`。

## 6. H×K 结果文件说明

| 文件 | 内容 |
|---|---|
| `robustness_details.csv` | 每个 K×H 的交易日数、IC观测数、费后收益、Sharpe、最大回撤、换手、IC和RankIC |
| `robustness_summary.csv` | 按 K 排列、按 H 展开的 Sharpe、RankIC和年化收益宽表 |
| `net_sharpe_heatmap.png` | 费后 Sharpe 热力图 |
| `rank_ic_heatmap.png` | RankIC 均值热力图 |
| `annual_return_heatmap.png` | 费后年化收益热力图 |

H×K 报告只运行 Rank 组合，因此它适合参数比较；如果某个单元格表现值得深入研究，再用 `main.py` 对该 K/H 运行完整报告。

## 8. 常用参数参考

### main.py

| 参数 | 默认值 | 说明 |
|---|---:|---|
| `--factor` | `basis_momentum` | 因子模块名称，如 `carry` |
| `--factor-param` | 无 | 因子参数，使用 `key=value`，可重复传入 |
| `--start` | `20190101` | 开始日期，格式 `YYYYMMDD` |
| `--end` | `20260710` | 结束日期，格式 `YYYYMMDD` |
| `--rebalance-freq` | `1` | 正整数 H，或 `W-MON` 至 `W-FRI` |
| `--cost-rate` | `0.0005` | 单边交易成本 |
| `--min-assets` | `10` | 一个横截面至少需要的有效商品数 |
| `--group-count` | `5` | 分组数量 |
| `--rolling-window` | `20` | IC图滚动观测期数；周频下20表示20周 |
| `--nw-lags` | `5` | Newey-West显著性检验滞后阶数 |
| `--signal-min-days-to-maturity` | `0` | 计算因子时信号合约的最低剩余日历日数 |
| `--trade-min-days-to-maturity` | `45` | 组合交易合约的最低剩余日历日数 |
| `--zscore-clip` | `3.0` | Z-score截尾阈值 |
| `--result-dir` | `results/` | 结果根目录 |

### src.hk_robustness

| 参数 | 默认值 | 说明 |
|---|---:|---|
| `--factor` | `carry` | 必须暴露 `lookback` 参数的因子 |
| `--start` | `20220101` | 开始日期 |
| `--end` | `20251231` | 结束日期 |
| `--k-values` | `30 60 90 120` | 一个或多个正整数 K |
| `--h-values` | `1 5 10` | 一个或多个正整数 H |
| `--cost-rate` | `0.0005` | 单边交易成本 |
| `--min-assets` | `10` | 最低有效商品数 |
| `--nw-lags` | `5` | IC显著性检验滞后阶数 |
| `--signal-min-days-to-maturity` | `0` | H×K信号合约的最低剩余日历日数 |
| `--trade-min-days-to-maturity` | `45` | H×K交易合约的最低剩余日历日数 |
| `--result-dir` | `results/` | 结果根目录 |

默认 `0/45` 表示信号始终跟随真实成交量主力/次主力，而交易继续保留
45天换月缓冲。如需复现旧的统一限制口径，显式加入：

```bash
--signal-min-days-to-maturity 45 \
--trade-min-days-to-maturity 45
```

随时可以查看程序当前支持的参数：

```bash
python main.py --help
python -m src.hk_robustness --help
```

## 9. 验证运行是否成功

程序成功结束时会打印结果目录。例如：

```text
Research complete: .../results/carry/carry-20230101-20260710/every_5_trading_days
```

或：

```text
Robustness complete: .../results/carry/carry-robustness-20230101-20260710-K30_60_90_120-H1_5_10
```

进一步确认：

1. 查看 `run_config.csv`，检查日期、`factor_lookback` 和 `rebalance_freq`。
2. 查看 `strategy_metrics.csv`，确认 Rank/Z-score 两行指标均已生成。
3. 查看 `ic_summary.csv` 和 `ic_series.csv`，确认 IC/RankIC 存在有效观测。
4. H×K 报告检查 `robustness_details.csv` 行数是否等于 `K数量 × H数量`。

## 10. 常见问题

### main.py 多 K 结果被覆盖

原因是 Carry 的标准目录名没有包含 K。批量运行时给每个 K 使用不同的 `--result-dir`，或者改用 H×K 工具。

### H=5 为什么不是每周五

整数 H 从样本首个交易日开始每隔 H 个交易日选一次信号日。需要周末调仓时使用 `--rebalance-freq W-FRI`。

### H×K 提示拒绝覆盖已有结果

H×K 工具会把 K/H 网格写入默认目录名，不同网格可以共存。完全相同的因子、日期和网格仍会保护现有 CSV 和热力图；此时使用新的 `--result-dir` 重跑，不要覆盖原结果。

### 运行时间较长

完整报告会同时运行 Rank 和 Z-score；H×K 会对每个 K/H 运行一次 Rank 回测。先缩短日期区间或减少 K/H 数量做测试，确认配置后再运行完整样本。

### `unable to open database file`

确认数据库位于项目父目录的 `data/db/huatai_quant.db`，并确保当前用户拥有读取权限。数据库路径由 `config/settings.py` 中的 `DB_PATH` 管理。

## 11. Close-to-close 敏感性说明

`src/close_to_close_sensitivity.py` 当前提供底层回测函数，但没有独立命令行入口。因此不能像 `main.py` 或 `src.hk_robustness` 一样通过一条正式 CLI 命令重建完整敏感性报告。

已有的 `results/carry/carry_close_to_close_sensitivity_*` 属于之前生成的分析结果。若后续需要稳定复跑，应先为该模块增加正式 CLI 和结果保存入口；在此之前不要在文档中使用未经代码支持的命令。
